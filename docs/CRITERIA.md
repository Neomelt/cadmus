# 验收标准（CRITERIA）

> 状态：草案 v0.1 · 2026-10-11
> **先于实现注册。** 实现期间若需修改本文件，修改须单独提交并说明理由——标准不因实现困难而移动。
> 每条标准 = 场景 + 通过阈值 + 检验方式。无法检验的条目一律不写入。

**重排质量抽样协议**（CR-1 使用，人工但可复现）：每份样本取 3 个页面（含至少 1 页含图/公式），从原文人工转录 3 个段落；检验重排结果中这 3 段文字**内容一致且顺序正确**。

## CR-1 双栏重排成立（go/no-go）

- **场景**：打开 F1，视口宽度 = iPad 竖屏半屏（约 600 CSS px）。
- **通过**：
  1. 正文以**单列流式**呈现（非整页缩放、非水平拖动）；
  2. 抽样协议中的段落全部命中且顺序正确；
  3. 正文字号 ≥ 16px 时可连续阅读，无需缩放操作。
- **检验**：`reader-cli reflow F1.pdf --viewport 600x800 --dump text` 输出与人工转录对照；UI 人工确认（M2 起）。
- **失败处理**：此项不通过则停止后续开发，回到布局分析。

## CR-2 原子块完整性

- **场景**：同 CR-1。
- **通过**：F1/F2 中的公式、图、表、代码块在其出现位置**完整呈现**，无跨栏截断、无乱序字符流；每页允许的降级（整页位图）≤ 1 页且不连续。
- **检验**：重排结果中统计原子块数量与原文一致；人工检查 3 处公式与 2 张图。

## CR-3 连续性

- **场景**：阅读中途执行：改字号 → 旋转设备 → 杀进程重开。
- **通过**：三种操作后均回到**同一段落**（允许 ±1 行偏差，不允许跳页/跳章）；滚动阅读中无内容跳动。
- **检验**：人工操作记录，位置由 `positions` 表核对。

## CR-4 标注轻量

- **场景**：选中一句话，高亮并写一条笔记。
- **通过**：从选中到高亮完成 ≤ 3 步；写笔记不离开正文视图；全程无弹窗。
- **检验**：操作录像 + 步数计数。

## CR-5 批注回流闭环（产品核心）

- **场景**：M4 后在 App 中做 3 处高亮 + 1 条笔记 → 桌面 `syncd` 运行中。
- **通过**：`知识库/00 Inbox/` 下出现 Markdown，含 4 条记录；每条含：原文引用、书名、页码/章节、定位回链；重复同步不产生重复条目（幂等）。
- **检验**：文件 diff + 二次同步对比。

## CR-6 源与离线

- **场景**：添加一个 OPDS 源（公版书目），下载一本 → 断网 → 阅读、批注、重启。
- **通过**：断网后全部功能可用；网络恢复后自动继续未完成下载；网络异常时**零可见错误提示**。
- **检验**：人工操作 + 日志检查（日志允许报错，UI 不允许）。

## CR-7 工程指标

| 指标 | 阈值 | 检验 |
|---|---|---|
| 冷启动 → 首屏 | < 500ms | 真机测量 ×5 取中位数 |
| F1 首次重排（20 页） | < 2s | 同上 |
| 滚动帧率 | 60fps | 真机 profiler |
| 单文档内存 | < 150MB | 同上 |
| 离线启动 | 完整可用 | 飞行模式重启 |

---

## 检验纪律

- CR-1/2/3 在 M1 用 CLI + 抽样协议检验（无需 UI）；M2/M3 用真机复检；
- CR-4/5/6 从 M2 起生效；
- 任何一条不通过：**先修这条，不叠加新功能**；
- 每条标准必须以"可观测行为"表述；禁止改为"代码已实现 X"这类无法观测的验收。
