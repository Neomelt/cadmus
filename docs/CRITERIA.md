## CR-1 双栏重排成立（go/no-go）

- **场景**：打开 F1，视口宽度 ≈ 600 CSS px（iPad 横屏半屏 / Split View）。
- **通过**：
  1. 正文以**单列流式**呈现（非整页缩放、非水平拖动）；
  2. 抽样协议中的段落全部命中且顺序正确；
  3. 正文字号 ≥ 16px 时可连续阅读，无需缩放操作。
- **检验**：`cadmus-cli reflow F1.pdf --viewport 600x800 --dump text` 输出与人工转录对照；UI 人工确认（M2 起）。
- **参考观察（不计入 go/no-go）**：Android 手机宽度（约 390 CSS px）下是否仍无需缩放、连续可读。
- **失败处理**：此项不通过则停止后续开发，回到布局分析。

## CR-2 原子块完整性

- **场景**：同 CR-1。
- **通过**：F1/F2 中的公式、图、表、代码块在其出现位置**完整呈现**，无跨栏截断、无乱序字符流；每页允许的降级（整页位图）≤ 1 页且不连续。
- **检验**：重排结果中统计原子块数量与原文一致；人工检查 3 处公式与 2 张图。

## CR-3 连续性

- **场景**：阅读中途执行：改字号 → 旋转设备 → 杀进程重开。
- **通过**：三种操作后均回到**同一段落**（允许 ±1 行偏差，不允许跳页/跳章）；滚动阅读中无内容跳动。
- **检验**：人工操作记录，位置由 `positions` 表核对。

## CR-4 标注轻量

- **场景**：选中一句话，高亮并写一条笔记。
- **通过**：从选中到高亮完成 ≤ 3 步；写笔记不离开正文视图；全程无弹窗。
- **检验**：操作录像 + 步数计数。

## CR-8 EPUB / TXT 阅读体验（第一期核心）

- **场景**：导入 F5（EPUB 小说）、F6（大 TXT），连续阅读 ≥ 30 分钟。
- **通过**：
  1. 打开即显示正文；F6 首次分页 < 1s；
  2. 排版可调（字号/行宽/行距/边距/主题），修改后位置保持（见 CR-3）；
  3. 目标行宽默认落在舒适区（中文 25–40 字/行）；
  4. 长时段阅读无视觉疲劳性缺陷：无滚动跳动、无闪烁、翻章无白屏。
- **检验**：CLI 输出 + 人工长时段试读（M2 起）。

## CR-9 批注导出

- **场景**：3 处高亮 + 1 条笔记 → 导出（系统分享面板或文件导出）。
- **通过**：得到 Markdown 文件，含 4 条记录，每条有原文引用、书名、进度/页码定位；重复导出不产生重复条目（幂等）。
- **检验**：文件 diff + 二次导出对比。

## CR-5 批注回流笔记软件（第二期：Obsidian / 飞书等）

- **场景**：在 App 中做 3 处高亮 + 1 条笔记 → 导出到笔记软件（Obsidian 仓库写入，或经 `syncd` 局域网接收）。
- **通过**：目标仓库出现对应 Markdown，含 4 条记录（原文引用、书名、进度/页码定位）；重复导出/同步不产生重复条目（幂等）。
- **检验**：文件 diff + 二次同步对比。

## CR-6 源与离线

- **场景**：添加一个 OPDS 源（公版书目），下载一本 → 断网 → 阅读、批注、重启。
- **通过**：断网后全部功能可用；网络恢复后自动继续未完成下载；网络异常时**零可见错误提示**。
- **检验**：人工操作 + 日志检查（日志允许报错，UI 不允许）。

## CR-7 工程指标

> 基线设备：iPad 第 9 代（2021）；Android 中端机（2021 年档，4GB RAM）。

| 指标 | 阈值 | 检验 |
|---|---|---|
| 冷启动 → 首屏 | < 500ms | 真机测量 ×5 取中位数 |
| F1 首次重排（20 页） | < 2s | 同上 |
| 滚动帧率 | 60fps | 真机 profiler |
| 单文档内存 | < 150MB | 同上 |
| 离线启动 | 完整可用 | 飞行模式重启 |

## 检验纪律

- **第一期标准**：CR-1/2/3/4/6 (离线部分)/7/8/9；
- **第二期标准**：CR-5、CR-6（源部分）；
- CR-1/2/8 在 M1 用 CLI 检验（无需 UI）；CR-3/4/9 从 M2 起生效（真机）；M2/M3 逐项真机复检；
- 任何一条不通过：**先修这条，不叠加新功能**；
- 每条标准必须以"可观测行为"表述；禁止改为"代码已实现 X"这类无法观测的验收。
