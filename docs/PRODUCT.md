## 1. 概述（Executive Summary）

**cadmus 是一个把书读好的平板阅读器。**

它解决四个具体问题：① 双栏 PDF（论文、教材）在窄屏上无法舒适阅读；② 主流阅读器的排版与数据都不属于用户；③ 阅读产出（高亮、笔记）无法顺畅流向用户自己的笔记系统；④ 中文排版（标点、中英混排、禁则）普遍不达标。

产品以「**阅读体验**」为唯一核心：本地文件进，舒服的排版、PDF 重排、完全离线；批注一键导出为 Markdown。

**要做成什么样**：读完一章后记得的是内容，不是 UI——阅读器在意识里不存在。

**一句话边界**：不是书城，不是笔记软件，不是阅读社交。是一个阅读器，加一个可选的批注出口。

## 2. 背景与研究（Background）

### 2.1 问题陈述

| # | 问题 | 现状后果 |
|---|---|---|
| P1 | 固定版式 PDF 不适应窄屏 | 双栏论文被迫缩放拖动；字号不可调；阅读疲劳 |
| P2 | 本地书库缺少"舒服的本地阅读器" | 要么云优先（数据托管、订阅），要么体验粗糙 |
| P3 | 批注被锁在应用或云内 | 阅读产出无法复用；导出格式私有或受限 |
| P4 | 中文排版（标点、中英混排、禁则）普遍不达标 | 读中文材料时持续的低质体验 |

### 2.2 竞品格局（2026-10 调研）

| 类别 | 代表 | 无法弥补的缺陷 |
|---|---|---|
| 系统/生态 | Apple Books、Kindle | 锁商店；自有库进不去；批注出不来 |
| 云阅读 | Readwise Reader、Matter | 云优先、订阅制；PDF 重排有限 |
| 本地阅读 | Yomu、KyBook、PDF Expert | 无重排；导出受限；无同步 |
| 专业标注 | MarginNote、LiquidText | 纸张模型；无重排；私有格式 |
| 中文系 | 微信读书、掌阅 | 云书城逻辑；本地库无法进入 |
| 开源 | KOReader | 强，但无 iPad 版；触屏 UX 差 |

**结论**：「移动端 PDF 重排 × 本地优先 × 批注导出」三者同时做完整的，目前不存在。Rust 生态中相关开源项目多为 0★ 停更状态（详见 `CRITERIA.md` 与调研记录）。

### 2.3 关键假设

| # | 假设 | 验证方式 | 风险 |
|---|---|---|---|
| A1 | 目标用户（含产品作者）愿在平板上持续阅读 ≥30 分钟 | 自用验证（狗粮） | 低 |
| A2 | 布局分析可达到"双栏论文连续可读"的质量 | M1 验收（CR-1，go/no-go） | 高 |
| A3 | 系统 WebView 的中文排版足够好，无需自研排版引擎 | M1/M2 实测（CR-8） | 中 |
| A4 | 本地优先（无账号、无云）是可接受的形态 | 自用验证 | 低 |

## 3. 目标用户（Users）

### 3.1 用户画像（Persona）

**P1 · 主用户「研究生/工程学习者」**（产品作者本人即原型用户）

- 在 iPad 上读论文、教材、技术书；有自有文件库（PDF/EPUB/TXT）
- 对排版敏感，厌恶缩放拖动；阅读时间长
- 期望高亮与笔记能进入自己的 Markdown 知识库（Obsidian 等）
- 技术背景强，容忍 Beta 版产品，愿意长期吃狗粮

**P2 · 次用户「重度本地读者」**

- 有大量 EPUB/TXT 小说或教材；用平板长时间阅读
- 需要：好排版、离线、无广告无推荐
- 不要求笔记集成

**非目标用户**：只看商城正版书的普通消费者；需要社交/推荐/排行榜的用户。

### 3.2 核心使用场景（Jobs to be Done）

| # | 场景 | 用户任务（JTBD） | 对应功能 |
|---|---|---|---|
| S1 | 读小说 | "我想连续读两小时不被打断" | 流式阅读、主题、进度记忆 |
| S2 | 读教材 | "我要对照翻阅和做记号" | 目录、标注、书签（全文搜索为一期争取） |
| S3 | 读论文 | "我要在窄屏上读完一篇双栏论文" | PDF 重排、原子块、跳转 |
| S4 | 收集灵感 | "我想把书中所得记进我的笔记软件" | 批注导出（一期）/ 回流（二期） |

## 4. 用户旅程（User Journey）

### J1 · 首次使用（Import → Read）

```
收到 PDF/EPUB 文件（邮件/网盘/AirDrop/下载）
  → 通过系统"打开方式 / 分享"选择 cadmus
  → 首次打开：自动构建可读版本（PDF 重排 / EPUB 解析）
  → 直接进入正文，无引导页、无注册、无弹窗
  → 打开即读（<500ms 首屏），排版使用全局默认值
```

**设计要点**：零配置启动；排版参数跟随用户（不是每本书单设）；首屏前不出现任何对话框。

### J2 · 日常阅读（Reading Loop）

```
拿起平板 → 打开 cadmus → 首页展示"继续阅读"卡片
  → 从上次语义位置精确恢复（±0）
  → 阅读：滚动为主，可选分页；随时调字号/主题
  → 高亮/书签/笔记（≤3 步）
  → 退出时静默保存位置与标注
```

### J3 · 双栏论文（Reflow Path）

```
打开双栏 PDF → 自动检测分栏 → 重排为单列流式
  → 公式/图/表/代码以完整块随文流动（不被拉直/截断）
  → 需要对照原页时，一键切"原始页视图"再切回（位置保持）
```

### J4 · 批注导出（Export Path）

```
读完全书 → 进入"标注"视图 → 一键导出
  → 系统分享面板 / 存到"文件" App（Markdown）
  → 内容：原文引用 + 书名 + 进度定位 + 我的笔记
  → 重复导出幂等，不产生重复条目
```

### J5 · 大文件（Robustness Path）

```
导入 >5MB 中文 TXT → 编码探测（GB18030/UTF-8/Big5）
  → 章节自动切分（卷/章正则）→ <1s 可读
  → 章节跳转即达；全程无卡顿、无白屏
```

## 5. 产品设计原则（Design Principles）

### 5.1 总判据

**好阅读体验 = 阅读器消失。** 一切决策用两条过滤器检验：

1. 它让眼睛少做功了吗？
2. 它让读者少做决定了吗？

两者都不满足 → 砍掉。

### 5.2 可操作指标

| 维度 | 口径 |
|---|---|
| 正文度量 | 西文 45–75 字符/行；中文 25–40 字/行；行距 1.5–1.7 |
| 重排正确性 | 公式/图/表/代码为不可分割原子块；阅读顺序错误率 < 1/页 |
| 连续性 | 长文默认滚动；字号/旋转/重启后位置不变 |
| 零阻塞 | 点开即渲染；无启动页、无对话框 |
| 跳转 | 目录/书签/进度跳转 < 1s；返回成本 < 1s |
| 标注 | 选中到高亮完成 ≤ 3 步；不离开正文 |
| 中文排版 | 全角标点、悬挂标点、中英自动间距、简繁正确 |
| 位置记忆 | 语义锚点（块 + 字符偏移），不依赖页码 |
| 零打断 | 阅读中零弹窗；失败静默重试 |

> 手机（窄屏）的舒适区间相应收窄：中文约 20–30 字/行。

### 5.3 反模式（Anti-goals）

- 翻页动画、纸张拟物、书脊阴影；
- 每本书单独设置排版；
- 把"查看大图"作为公式/图表的呈现方式；
- 阅读中弹窗（同步、电量、更新、推荐）；
- 把批注工具做成一级入口。

## 7. 非功能需求（Non-functional Requirements）

### 7.1 性能

| 指标 | 目标 | 检验 |
|---|---|---|
| 冷启动 → 首屏 | < 500ms | 真机 ×5 中位数 |
| PDF 首次重排（20 页双栏） | < 2s（后台，不阻塞） | 真机 |
| 5MB TXT 首次分页 | < 1s | 真机 |
| EPUB 打开（单章可见） | < 500ms | 真机 |
| 滚动帧率 | 60fps | profiler |
| 单文档内存 | < 150MB | profiler |

> 基线设备：iPad 第 9 代（2021）；Android 中端机（2021 年档，4GB RAM）。所有指标在基线设备上测量。

### 7.2 可靠性与数据

| 项 | 要求 |
|---|---|
| 崩溃 | 阅读中崩溃为最高优先级缺陷（S0） |
| 数据持久 | 位置/标注实时落盘；杀进程不丢 |
| 幂等 | 导出/同步重复执行不产生重复数据 |
| 降级 | 布局分析失败按页降级为位图，不阻断阅读 |

### 7.3 隐私与安全

| 项 | 决策 |
|---|---|
| 数据收集 | 零收集；无遥测、无账号 |
| 网络使用 | 一期全程离线；二期仅局域网（用户主动开启） |
| 权限 | 最小化：仅文件访问；不申请通讯录/位置/相机 |
| 用户数据 | 全部本地；导出物属用户所有，格式为开放 Markdown |

### 7.4 兼容性

| 项 | 范围 |
|---|---|
| 平台 | iOS 16+（仅 iPad，不含 iPhone）；Android 10+（平板与手机） |
| 格式 | EPUB 2.0/3.x；PDF 1.4–2.0（含无文本层降级路径）；TXT（GB18030/UTF-8/Big5/UTF-16） |
| 不含 | MOBI/AZW3/DjVu/CHM；DRM 加密内容 |
| 语言 | 简体中文优先；英文完整支持；排版规则适配中日韩标点 |

### 7.5 可访问性

- 支持系统字体缩放（Dynamic Type）；支持旁白（VoiceOver/TalkBack）基础导航；
- 夜间模式对比度符合 WCAG AA。

## 9. 范围与优先级（Scope & Release Plan）

### 9.1 里程碑

| 阶段 | 目标 | 可验证成果 | 关联 CR |
|---|---|---|---|
| M1 · 引擎 | 阅读引擎在桌面成立 | CLI：PDF/EPUB/TXT → 可读输出 | CR-1/2/8 |
| M2 · Android | 真机（平板/手机）可读可批注 | 论文与小说连续读完；导出 Markdown | CR-3/4/9 |
| M3 · iOS（iPad） | iPad 真机 | TestFlight；全部一期验收通过 | 全部一期 |
| M4 · 笔记接入 | 批注回流（二期） | Obsidian/飞书出现 Markdown | CR-5 |
| M5 · 源 | OPDS/WebDAV（二期） | 从 OPDS 下载并阅读 | CR-6 |

排序原则：**先把书读好，再把笔记送出去。** 任一阶段，阅读体验修复优先于新功能。

### 9.2 明确不做

- 书城、内容推荐、社交、排行榜；
- 云优先账号体系与云同步；
- iPhone 客户端（iOS 侧仅 iPad；手机端只做 Android）；
- MOBI/AZW3/DjVu/CHM 等格式与 DRM 加密内容（仅支持无 DRM 的 PDF/EPUB/TXT）；
- 自研 PDF 渲染引擎（使用现有渲染库，工程投入集中在重排与阅读体验）；
- 桌面 GUI 客户端（伴生程序为纯 CLI）。

### 9.3 商店合规策略

- 上架版本**不含**任何内容销售与内购；用户自行导入本地文件，或使用标准协议源（OPDS/WebDAV）；
- 规则源（网页采集）不预置、不托管源列表，由用户自行添加；该能力仅用于侧载/TestFlight 分发，避免商店审核风险；
- 依据：App Store 审核指南 3.1.3(a)「Reader Apps」允许应用访问用户已在别处获得的内容，且对本地导入类阅读器无内购要求（详见 `RESEARCH.md` §5）。

## 10. 风险与应对（Risks）

| # | 风险 | 等级 | 应对 |
|---|---|---|---|
| R1 | iOS 构建依赖 macOS（Linux 无法出包） | 高 | macOS CI runner；本地只做 Android |
| R2 | 重排质量达不到"连续可读" | 高 | M1 桌面先行 + CR-1 go/no-go 门 |
| R3 | PDF 渲染库依赖（AGPL/预编译二进制） | 中 | 隔离为可替换 crate |
| R4 | EPUB 体验无辨识度 | 中 | 长时段对照试读（CR-8）；"不输主流 + PDF 重排明显更强"为底线 |
| R5 | 中文排版细节（禁则/悬挂） | 中 | 明确列入 CR |
| R6 | 长期维护衰减 | 中 | 以"每天自己用"驱动；文档先行（本档） |

## 11. 决策记录（Decision Log）

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
