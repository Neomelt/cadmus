# cadmus

> 希腊神话里，卡德摩斯把腓尼基字母带给了希腊。cadmus 做的事一样：把文本带到新的载体上。

把论文和书变好读的平板阅读器，和一个让笔记回到知识库的管线。

- 平台：iOS（主）+ Android；Rust 核心 + Tauri 2
- 差异化：**移动端 PDF 重排 × 本地优先 × 批注回流笔记系统**
